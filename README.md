# ComfyUI-Chatterbox

Chatterbox TTS integration for ComfyUI - Voice cloning with 3 model variants.

## 🎯 Models

| Model | Size | Languages | Speed | Special Features |
|-------|------|-----------|-------|------------------|
| **Chatterbox** | 500M | English | Normal | Standard quality |
| **Chatterbox Turbo** | 350M | English | 6x faster | Paralinguistic tags |
| **Chatterbox Multilingual** | 500M | 23 languages | Normal | Multi-language |

## 🌍 Supported Languages (Multilingual)
Arabic • Danish • German • Greek • English • Spanish • Finnish • French • Hebrew • Hindi • Italian • Japanese • Korean • Malay • Dutch • Norwegian • Polish • Portuguese • Russian • Swedish • Swahili • Turkish • Chinese

## 📦 Installation

### ComfyUI Manager
1. Open ComfyUI Manager
2. Search "Chatterbox"
3. Install

### Manual
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/YOUR_USERNAME/ComfyUI-Chatterbox.git
cd ComfyUI-Chatterbox
pip install -r requirements.txt
